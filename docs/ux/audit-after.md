# 前端 UI 改造后验收记录

日期：2026-10-14。使用 `MOCK_MODE=true` 的本地 Streamlit 页面检查改造结果；未连接 API、Worker 或数据库。七个页面均在 1440×900、1280×800、390×844 下查看。CUA 浏览器会话可以展示截图，但不提供把截图保存到仓库的接口，因此本文记录实测结果，不附二进制图片。

## 页面与视口

| 页面 | 1440×900 / 1280×800 实测 | 390×844 实测 |
|---|---|---|
| 工作台 | 页面标题、概览和图表层级清楚；仓库与任务入口在主要内容区。 | 侧栏自动收起；卡片纵向排列，内容宽度为视口宽度。 |
| 发现仓库 | 搜索、结果和仓库操作清晰分组。 | 搜索字段与结果卡片纵向排列；侧栏收起后可直接操作。 |
| 我的分析库 | 筛选和仓库操作收敛在各自区块；空库态提供搜索入口。 | 列表与筛选纵向排列；侧栏收起后主体完整可见。 |
| 仓库详情 | 基础信息、分析深度与模块结果分区展示。 | 指标和操作按窄屏纵向布局显示。 |
| 仓库对比 | 已选仓库和对比结果使用清楚的分区；空态可继续搜索或添加。 | 对比内容纵向布局；侧栏收起后主体完整可见。 |
| 研究分析 | 数据范围和筛选与分析视图分组展示。 | 筛选控件、指标和视图纵向排列。 |
| 任务中心 | 系统状态收在可展开区域，活动任务与历史任务分别呈现。 | 活动任务与任务摘要按窄屏排列，侧栏收起后主体可见。 |

1280×800 和 390×844 下逐页测量 `window.innerWidth`、`documentElement.scrollWidth` 与 `body.scrollWidth`，七个页面均无横向溢出；窄屏下导航侧栏自动收起。桌面视口下导航侧栏保持展开。

## 交互场景

- 在发现页搜索 `psf/requests`，显示仓库信息与 GitHub 链接；添加后反馈“已加入分析库”及“最近任务：已排队”，没有把排队状态误报为完成。
- 空分析库场景显示空状态及“搜索仓库 → 加入分析库 → 查看分析结果”的后续路径。
- “模块进度 v2”场景在任务中心显示 38% 阶段进度，明确说明不代表数据覆盖率；模块覆盖单独显示，完成时间暂不可估计时不提供 ETA。
- 任务进度 AX 树在 Streamlit fragment 更新后保留一组过期节点；浏览器当前截图只显示一份进度摘要和一份模块进度区。最终视觉验收以页面截图为准。
