# 前端 UI 基线审查

基线取自 `main@b2838605f60f1a4a8a45391417cda7e3dfe0d015`。改动前用该 commit 的临时源码副本和 `MOCK_MODE=true` 启动 Streamlit；没有连接 API、Worker 或数据库。七个页面均在 1440×900、1280×800、390×844 下实际截图检查。截图在本次浏览器会话中查看，但 CUA 未提供将图像保存到仓库的接口，因此本记录保留实测结论，不附二进制图片。

## 实测观察

| 页面 | 1440×900 / 1280×800 实测 | 390×844 实测 |
|---|---|---|
| 工作台 | 产品大标题与“数据概览”重复；Mock 横幅和 API 成功文本占据首屏，研究样本选择优先于仓库主流程。 | 展开的侧栏覆盖主体，右侧仅露出少量内容。 |
| 发现仓库 | 全局重复标题和提示占高；搜索表单包含关键词、语言、最低 Star、排序，结果前还放置整宽说明块。 | 展开的侧栏覆盖搜索表单和结果。 |
| 我的分析库 | 全局重复标题和提示占高；筛选表单后常驻比较多选器，仓库行和操作区垂直占用较多。 | 展开的侧栏覆盖列表主体。 |
| 仓库详情 | 页面先显示分析深度选择器；深度动作、摘要、历史趋势和数据说明分布在不同区段，首屏下方才出现多 Tab。 | 展开的侧栏覆盖详情指标和分析操作。 |
| 仓库对比 | 全局重复标题和提示占高；标准空库状态只给出“至少两个成员”的说明，没有就地搜索和分页入口。 | 展开的侧栏覆盖页面主体。 |
| 研究分析 | 首屏直接出现数据集、分组、语言筛选和五个统计 Tab，样本口径说明较晚出现。 | 展开的侧栏覆盖研究内容。 |
| 任务中心 | API、Worker、队列以三张大指标呈现；配额与心跳信息、历史筛选和 CSV 导出堆在同页。 | 展开的侧栏覆盖状态和任务列表。 |

以上内容来自所列视口的截图观察。超过首屏的操作次序、比较仅读取第一页及具体交互边界由基线源码审查补充；没有把源码推断写成像素观察。
